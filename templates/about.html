About this project

An academic prototype for organizing and analyzing electricity meter readings.

Project purpose

PowerPulse presents consumer and meter records, calculates consumption from cumulative readings, and highlights meters that meet a configurable demonstration rule.

Technology stack

  • Python and Flask — web routes and application logic
  • MySQL — consumers, meters and readings
  • HTML and CSS — interface and responsive layout
  • Chart.js — consumption visualizations

Important limitations

  • Uses data stored in the local MySQL database.
  • Does not connect to real utility meters or provider APIs.
  • High-usage alerts use a demonstration threshold.
  • Charts only represent consumption that can be calculated from stored readings.
